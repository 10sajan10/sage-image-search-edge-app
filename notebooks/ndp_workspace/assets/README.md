# Reusable caption asset

`gemma3_4b_it_edge_v1_benchmark_captions.jsonl` is the original caption export
generated by `gemma-3-4b-it` for edge_v1. Every row records `dataset`,
`image_id`, `caption`, `elapsed_seconds`, and `model`.

The file contains 32,177 captions -- every benchmark image.

Thirty-five CloudBench requests did not complete in the original edge_v1 run
(all `RuntimeError('timed out')`). They were later backfilled by
`ImageSearchatEdge/scripts/backfill_missing_captions.py`, which calls the
original pipeline's own `caption_image` against the same `gemma-3-4b-it`
endpoint with the same prompt and caption cleaner, so those rows are the same
kind of output as the rest -- not replacement text from another source. Their
`elapsed_seconds` are that run's real per-image timings (13.6-22.7s).

`gemma3_4b_it_edge_v1_benchmark_caption_errors.jsonl` is now empty and is kept
so a future run has somewhere to record new failures.

At runtime the notebook validates these rows against the downloaded image tree
and writes a derived, path-resolved copy to
`data/gemma3_4b_it_edge_v1_benchmark_captions_resolved.jsonl`. That derived file
is not new model output; it only adds each image's relative local path.
